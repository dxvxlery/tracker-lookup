Set up in a minute

Needs BetterDiscord. An account on the data source unlocks everything beyond comments.

Step 1
Download
Get the plugin from the latest release.
Step 2
Drop it in
Settings → BetterDiscord → Plugins → Open Plugins Folder.
Step 3
Enable
Turn on TrackerLookup. Comments work right away.
Session

One cookie. That’s it.

Copy tracker_session from your browser cookies, paste it into the settings and press Check. A whole “Copy as cURL” works too: the plugin finds the cookie in it.

It stays on your computer. Never share the plugin’s config file.
